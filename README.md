# 🚗 Revix – Vehicle Service Mobile App  

![Made with Kotlin](https://img.shields.io/badge/Made%20with-Kotlin-purple?style=for-the-badge&logo=kotlin)  
![Android Studio](https://img.shields.io/badge/IDE-Android%20Studio-brightgreen?style=for-the-badge&logo=androidstudio)  
![Status](https://img.shields.io/badge/Status-Completed-blue?style=for-the-badge)  

Revix is a **mobile application** developed as an **individual project** for the *Mobile Application Development (MAD)* module at **SLIIT**.  
It helps busy car owners by providing:  

- 🛢 **Personalized oil recommendations**  
- 🛒 **Oil & spare parts marketplace**  
- 🔧 **Mechanic service bookings**  

---

## 📱 Features  

✨ User Authentication – Login & Registration  
✨ Oil Recommendations – Based on vehicle type/model  
✨ Oil Store – Browse & purchase motor oils  
✨ Spare Parts Store – Shop a wide range of parts  
✨ Mechanic Services – Book trusted mechanics for repairs  
✨ Modern UI/UX – Minimal, clean, and responsive  

---

## 🛠 Tech Stack  

- **Language**: Kotlin 🟣  
- **IDE**: Android Studio 🖥  
- **UI Design**: XML (Layouts, Views, Strings, Colors) 🎨  
- **Version Control**: GitHub 🔗
